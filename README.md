# DAOL

The software code called Dynamic Analysis of Overhead Lines (DAOL) provides researchers and conventional designers with a tool that helps them gain a basic understanding of dynamic responses, such as ice or snow shedding. The input data required for numerical calculations are designed to be familiar to the user, so no specialised knowledge of cable dynamics is necessary.

The code is based on Absolute Nodal Coordinate Formulation (ANCF). ANCF is a finite-element method particularly well suited to analysing large rotations and deformations; an overhead transmission line can therefore be modelled as a mechanical multibody system requiring both dynamic and static analyses. An overhead line of arbitrary geometry can be divided into equivalent mechanical elements consisting of finite elements. These elements, combined with defined mechanical joints and constraints, describe the equivalent mechanical system– in this case, the overhead line.
